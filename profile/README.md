# HyperI

Software for collecting and analysing security and operational data in real time.

## Products

- HyperI Data Fusion Engine (DFE) -- real-time pipelines that receive, transform, load and archive event streams, run from a GitOps control plane. Start with [dfe-engine](https://github.com/hyperi-io/dfe-engine) and [dfe-infra](https://github.com/hyperi-io/dfe-infra).
- HyperI Edge Stream Hub -- collection of streaming data at the edge.

More at https://hyperi.io.

## Open source

- [scalo-rs](https://github.com/hyperi-io/scalo-rs) and [scalo-py](https://github.com/hyperi-io/scalo-py) -- the runtime our services share for config, logging, secrets and CLIs.
- [factbook-rs](https://github.com/hyperi-io/factbook-rs) -- a self-maintaining fact enricher, IP geolocation included.
- [logreducer](https://github.com/hyperi-io/logreducer) -- cut GB-scale logs down to a representative sample.
- [git-scrub](https://github.com/hyperi-io/git-scrub) -- remove AI tool residue and accidental data spill from git history.
- [claudemeter](https://github.com/hyperi-io/claudemeter) -- Claude Code usage in your status bar.

Each repository's LICENSE sets its terms.
